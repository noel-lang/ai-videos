# AI Videos

Arbeitsrepo fuer Video-Demos rund um KI-Agenten, LLM-Tools und einfache technische Erklaerungen.

## Projekte

- `001-wie-funktionieren-ki-agenten/`: Bun/OpenTUI-Demo fuer einen minimalen KI-Agenten mit Tool-Loop.
- `live_demo_ai_agent/`: Phasenplan und Anforderungen fuer eine Live-Coding-Demo.
- `research/`: Recherche-Notizen fuer Video-Inhalte.

## Lokal starten

```sh
cd 001-wie-funktionieren-ki-agenten
bun install
bun start
```

Echte `.env` Dateien, `node_modules`, Runtime-Workspaces und externe Recherche-Checkouts sind absichtlich nicht im Repo.
